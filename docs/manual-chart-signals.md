# Manual chart signals

Crypto Markets has an eighth tab, **سیگنال دستی**, with three compact, equally dark navigation cards: ranked symbols, chart analysis and existing active signals. The symbol card opens a full-width watchlist using the same market-cap order as crypto search; choosing a row returns to the full-width chart without a sidebar. It loads the local Lightweight Charts library only when needed. Entry, target, stop and expiry are chart handles supporting pointer/touch drag and keyboard arrows. The chart canvas is white with both grid directions disabled; its price axis remains logarithmic and supports vertical scaling. Margin, leverage and direction live in a separate aligned control bar above the canvas. Timeframe, chart type and drawing tools occupy one horizontally scrollable icon strip directly above the chart. The embedded chart uses the outer viewport height to avoid iframe resize feedback. The independent Phoenix drawing layer uses timestamp/price anchors and logarithmic price coordinates, with no dependency on Advanced Charts.

Margin is USDT collateral. Quantity is floor(margin × leverage / entry / quantityStep) × quantityStep. Target/stop dollar estimates use that quantity and direction, exclude fees/slippage, and update during drag and on margin/leverage changes. Expiry has no PnL estimate.

Preview validates instrument membership, tick size, leverage step/cap and minimum quantity/notional without queueing a trade. Confirmation posts a stable request UUID; uncertain retries preserve the frozen payload and reuse that UUID. After a lost response, the user can leave confirmation and return to reconcile the same submission. A successful POST adds a Pending ServerSignal to the existing durable queue; no new execution worker is introduced. The explicit Manual leverage is excluded from formula backfills. Manual registrations are not duplicated into Strategy 2.

Protection and expiry use the current engine: expiry activation at 25% entry-to-target distance, first protection at 50% with 20% stop, and second protection at 75% with 50% limit plus 20% market stop. These derive from the selected entry/target and support Long and Short. Initial expiry is the selected expiry line; subsequent adjustment remains engine-owned.

Origin `ManualChart` is persisted in queue clones and archive payloads. Manual initial expiries retain their analysis levels instead of undergoing the automatic-signal compaction. Results are now selected as ordinary or manual in the main Results page and notification journal, outside the manual editor. Both archive and journal filter source before applying pagination. A one-time journal enrichment assigns origin to older manual entries without replacing recovered wallet metadata. Active signals reuse the existing renderer, selection and cancellation logic inside the manual workspace.

Validation:

- ManualSignalTests: explicit levels/leverage, Long/Short dollar estimates, existing protection thresholds, tick collisions, leverage cap rejection, queue/archive restart and manual-only expiry reporting.
- manual-signals-ui-tests.cjs: full Crypto Markets initialization at 390/1280 px, ranked symbol rail, touch/mouse drag, live PnL, keyboard tick movement, touch drawing, Short mode, preview before commit, same-payload retry after a network failure and separate results.
- JournalSourceTests and journal-source-ui-tests: source isolation before pagination, owner privacy, legacy wallet preservation, separate UI caches and both results entry points.
- Existing server and interface regression suites.

No production orders are placed by these tests.

## Drawing workspace

The icon strip exposes exactly the tools requested from the reference screenshots: horizontal line, ray, info line, trendline, parallel channel, vertical line, pitchfork, horizontal ray, Fibonacci retracement, trend-based Fibonacci extension, trend-based Fibonacci time, Fibonacci time zone, Elliott impulse/correction/triangle/triple combination, XABCD, rectangle, arrow and text. Multi-point tools report the next required point while drawing. Elliott tools are manual annotations, not automatic wave detection. Degree supports the 15 requested names from Supermillennium to Minuscule, switching numeral/letter case, enclosure and size. Double-click/double-tap a drawing or select it and use the edit icon to set degree, connector visibility, color, width and opacity. Text content is inserted with textContent.

Use the cursor icon to select or drag a drawing, or drag an individual anchor. Delete removes the selected drawing; clear removes analysis drawings only. Undo reverses creation, movement, style edits, deletion and clearing, and removes the last unfinished anchor. Its bounded session history survives switching candle/line chart types. Keyboard Escape cancels unfinished placement, Ctrl/Cmd+Z undoes and Delete removes the selection. Drafts and drawing styles are retained per symbol/timeframe in sessionStorage; this is not cross-device cloud storage. Legacy logical-index drawings are converted to timestamps when first rendered.

Only candle and closing-price line charts are exposed; both retain the four independent signal-level handles and logarithmic axis. Supported intervals are 1, 5, 15, 30, 60, 240, D, W, M and 3M. Quarterly candles aggregate Bybit monthly candles by UTC calendar quarters (Jan/Apr/Jul/Oct), with first open, max high, min low, last close and summed volume, including the current partial quarter. The results live-chart endpoint uses the same aggregation for quarterly manual signals. Fibonacci price levels interpolate logarithmically; time-based tools use bar spacing. Parallel channels and pitchforks are constructed in the displayed logarithmic chart plane.

UI tests place all 20 tools on real mobile/desktop charts, exercise degree/style editing, undo edits/deletion/clearing and chart-type switches, and verify an icon-only single-row toolbar. Server tests validate every supported manual timeframe and quarterly aggregation across calendar/year boundaries.
