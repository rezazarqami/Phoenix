# فونیکس مستقل — اسکرین‌شات آزاد

`phoenix-android.apk` نسخهٔ مستقل با آیکون ققنوس طلایی است و مستقیماً بخش فونیکس را باز می‌کند.

این نسخه با شناسهٔ جدید `ir.marketsignalist.phoenix.standalone.capture` کنار برنامهٔ قدیمی نصب می‌شود؛ به‌روزرسانی نصب قدیمی نیست. گواهی امضای APK قدیمی با کلید موجود ساخت تفاوت دارد، بنابراین به‌روزرسانی همان بسته ممکن نیست. نیازی به حذف برنامهٔ قدیمی یا مدار و فونیکس نیست.

بعد از نصب با حساب فعلی فونیکس وارد شو. داده‌های سرور همان داده‌های حساب قبلی هستند؛ نشست محلی برنامهٔ قدیمی منتقل نمی‌شود.

- اسکرین‌شات آزاد است و FLAG_SECURE هنگام شروع و بازگشت پاک می‌شود.
- آیکون نسخهٔ مستقل از فایل اصلی phoenix-gold.jpg می‌آید و با آیکون مدار متفاوت است.
- شناسهٔ مدار همان ir.marketsignalist.phoenix.orbit باقی می‌ماند.
- آزمون اندروید نصب همزمان APK مستقل قبلی و جدید را بررسی می‌کند.
