# فونیکس ۱٫۹٫۵ — ورود با تم یخی

فقط `phoenix-android.apk` ارائه می‌شود. روی آخرین فونیکس مستقل ۱٫۹٫۳ یا ۱٫۹٫۴ نصب کن؛ شناسهٔ `ir.marketsignalist.phoenix.standalone.capture` و گواهی امضای آن حفظ شده‌اند. حذف برنامه یا نصب برنامهٔ جداگانه لازم نیست.

صفحهٔ ورود داخل اپ و وب با تم یخی، لوگوی آبی ارسالی و پس‌زمینهٔ کوهستان بازطراحی شده است. رفتار ورود، بازشدن مستقیم فونیکس، اسکرین‌شات و اعلان سیگنال حفظ شده‌اند. امکانات فضای شخصی، تقویم، حسابداری، پیامک و یادآوری حذف شده‌اند.

در CI، APK قبلی نصب و یک فایل محلی علامت‌گذاری می‌شود؛ سپس APK جدید با `adb install -r` روی آن نصب و باقی‌ماندن فایل بررسی می‌شود. آزمون‌های واحد، ورود و کنترل مسیرهای فونیکس نیز اجرا می‌شوند.

فایل‌های نصب بازنشستهٔ اپ ترکیبی از انتشارهای گیت‌هاب حذف می‌شوند. مسیر ساخت فعلی، شاخهٔ دارای همان کلید امضاست؛ در صورت نبودن کلید یا تفاوت گواهی، انتشار متوقف می‌شود و کلید تازه تولید نمی‌شود.
